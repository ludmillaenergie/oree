Installer Orée

Orée s'ouvre depuis un lien, sans compte. Tu peux la garder sur l'écran d'accueil de ton téléphone, comme une appli.

Ouvrir Orée

Depuis un ordinateur, scanne ce code avec l'appareil photo de ton téléphone.

Sur iPhone

  1. Ouvre Orée dans Safari, avec le bouton « Ouvrir Orée ».
  2. Touche le bouton Partager, le carré avec une flèche vers le haut.
  3. Choisis « Sur l'écran d'accueil ».
  4. Touche « Ajouter ».

Sur Android

  1. Ouvre Orée dans Chrome, avec le bouton « Ouvrir Orée ».
  2. Touche le menu, les trois points en haut à droite.
  3. Choisis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  4. Confirme.

Fais ces gestes depuis Orée, pas depuis cette page. Selon ton téléphone, les mots peuvent changer un peu. Orée marche aussi sans l'installer, directement dans le navigateur. Tes notes restent sur ton téléphone.
